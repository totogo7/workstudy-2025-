因为你用 **IDEA + Spring Boot**，前后端其实可以分开两个项目：

- **后端**：Spring Boot（Java） → 在 IDEA 里 main/java 下开发。
- **前端**：Vue + Element UI → 单独一个文件夹，通常放在项目根目录的 `library-frontend/`。

这样结构更清晰（类似苍穹外卖：`sky-take-out` 后端 + `sky-take-out-ui` 前端）。

## 🎨 主要界面代码（Vue + Element UI）

解释：每一个`.vue`文件都是一个「Vue 组件」—— 可以理解成一个「独立的小页面 / 功能块」，比如`Login.vue`就是 “登录页面” 这个功能块，`BookList.vue`就是 “图书管理页面” 这个功能块。每个组件都由 3 部分组成：

1. `<template>`：写 “页面上能看到的东西”（比如输入框、按钮、表格）；
2. `<script>`：写 “页面的逻辑”（比如点击按钮后发请求、加载页面时拿数据）；
3. `<style>`：写 “页面好不好看”（比如按钮颜色、输入框位置）。



### 1. 登录界面（Login.vue）

**`<template>` 部分：页面上能看到什么？**

页面上可以看到标题，用户名，密码登录按钮
	el-xxx开头的标签：都是「Element UI 组件」（别人写好的现成组件，你直接用，不用自己从零写输入框、按钮）；
	v-model：“双向绑定”—— 输入框和变量同步，比如你输入 “admin”，form.username就变成 “admin”，不用手动写代码拿输入框内容；
	@click：“点击事件”—— 点击按钮后触发指定的方法（这里是login()），相当于 “点击按钮后要做什么”。

**`<script>` 部分：页面的逻辑（点击登录后做什么）**

```vue
<template>
  <div class="login-container">
    <el-card class="login-card">
      <h2>图书管理系统 - 登录</h2>
      <el-form :model="form" label-width="80px">
        <el-form-item label="用户名">
          <el-input v-model="form.username"></el-input>
        </el-form-item>
        <el-form-item label="密码">
          <el-input type="password" v-model="form.password"></el-input>
        </el-form-item>
        <el-form-item>
          <el-button type="primary" @click="login">登录</el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>



<script>
 // 1. 引入Axios：Axios是专门发请求的工具（比如给后端发登录请求要用到它），引入工具
import axios from "axios";
 // 2. 导出这个Vue组件（让项目能识别它是个页面）
export default {
  name: "Login", //组件名字
  data() { //组件的“变量库”，存储变量
    return {
      form: { username: "", password: "" }
    };
  },
 // methods:组件的“方法库”——存页面要执行的逻辑（登录，拿数据）
  methods: {
 // async：表示这个方法是“异步的”（发请求要等后端响应，不能卡着页面）
    async login() {
 // ① 用Axios给后端发POST请求：
 // 地址是http://localhost:8080/user/login（后端的登录接口）
 // 传的数据是this.form（也就是输入的用户名和密码）
      let res = await axios.post("http://localhost:8080/user/login", this.form);
// ② 等后端响应后，判断登录成功还是失败：
 // 假设后端返回{code:1, data:"token", msg:"登录成功"}（code=1代表成功）        
      if (res.data.code === 1) {
// 成功：把后端返回的token存到浏览器（localStorage是浏览器的本地存储，关网页也不会丢）
        localStorage.setItem("token", res.data.data);
// 跳转到“图书列表页”（/books是路由地址，后面会讲）
        this.$router.push("/books");
      } else {
// 失败：弹出错误提示（this.$message是Element UI的提示组件）
        this.$message.error(res.data.msg);
      }
    }
  }
};
</script>

<style scoped>
.login-container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}
.login-card {
  width: 400px;
  padding: 20px;
}
</style>
```

`<style> `部分：页面的外观（让登录框居中、好看）



### 2. 图书管理界面（BookList.vue）

`<template>` 部分：页面上的表格、新增弹窗

`<script>` 部分：加载图书、新增 / 编辑 / 删除逻辑



```vue
<template>
  <div>
    <h2>图书管理</h2>
      
<!-- 新增图书按钮：点击后显示弹窗（dialogVisible变成true） -->
    <el-button type="primary" @click="dialogVisible = true">新增图书</el-button>

<!-- Element UI的“表格组件”：展示图书列表 -->
    <el-table :data="books" style="width: 100%" border>
         <!-- 表格列1：ID -->
      <el-table-column prop="id" label="ID" width="60"/>
        <!-- 表格列2：书名 -->
      <el-table-column prop="title" label="书名"/>
        <!-- 表格列3：作者 -->   
      <el-table-column prop="author" label="作者"/>
        <!-- 表格列4：状态 -->
      <el-table-column prop="status" label="状态"/>
        <!-- 表格列5：操作（编辑/删除按钮） -->
      <el-table-column label="操作">
          <!-- slot-scope="scope"：获取当前行的数据（scope.row就是当前行的图书信息） -->
        <template slot-scope="scope">
            <!-- 编辑按钮：点击时把当前行数据传给editBook()方法 -->
          <el-button size="mini" @click="editBook(scope.row)">编辑</el-button>
            <!-- 删除按钮：type="danger"是红色，点击时传当前行的id给deleteBook() -->
          <el-button size="mini" type="danger" @click="deleteBook(scope.row.id)">删除</el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- 新增/编辑弹窗 -->
    <el-dialog title="图书信息" :visible.sync="dialogVisible">
      <el-form :model="form">
          <!-- 弹窗里的表单：新增/编辑图书的输入框 -->
        <el-form-item label="书名"><el-input v-model="form.title"></el-input></el-form-item>
        <el-form-item label="作者"><el-input v-model="form.author"></el-input></el-form-item>
        <el-form-item label="状态">
          <el-select v-model="form.status">
            <el-option label="可借" value="available"/>
            <el-option label="已借出" value="borrowed"/>
          </el-select>
        </el-form-item>
      </el-form>
        <!-- 弹窗底部的按钮 -->
      <span slot="footer">
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" @click="saveBook">保存</el-button>
      </span>
    </el-dialog>
  </div>
</template>

<script>
import axios from "axios";
export default {
  data() {
    return {
      books: [],// 存所有图书列表（表格的数据源）
      dialogVisible: false, // 控制弹窗显示/隐藏（默认隐藏）
      form: { id: null, title: "", author: "", status: "available" }
    };
  },
    
 // created()：Vue的“生命周期钩子”—— 页面刚加载完成时自动执行
  created() {
    this.getBooks();// 页面一加载，就调用getBooks()拿图书列表
  },
    
  methods: {
       // ① 拿图书列表：给后端发请求，获取所有图书
    async getBooks() {
         // 发GET请求到后端的图书列表接口
      let res = await axios.get("http://localhost:8080/book/list");
         // 把后端返回的图书数据（res.data.data）赋值给books，表格就会显示
      this.books = res.data.data;
    },
      // ② 保存图书：新增或编辑图书（共用一个方法）
    async saveBook() {
        // 发POST请求到后端的保存接口，传表单里的图书数据（this.form）
      await axios.post("http://localhost:8080/book/save", this.form);
      this.dialogVisible = false;// 保存成功后，关闭弹窗
      this.getBooks();// 重新拿一次图书列表，表格刷新（显示新增/编辑后的结果）
    },
      // ③ 编辑图书：点击“编辑”按钮时执行
    editBook(book) {
        // 把当前行的图书数据（book）复制给form（弹窗表单就会显示当前图书的信息）
      this.form = { ...book };
      this.dialogVisible = true;// 显示弹窗
    },
      // ④ 删除图书：点击“删除”按钮时执行
    async deleteBook(id) {
        // 发DELETE请求到后端的删除接口，传要删除的图书id
      await axios.delete(`http://localhost:8080/book/${id}`);
      this.getBooks();// 重新拿图书列表，表格刷新（删除的行就不见了）
    }
  }
};
</script>
```

### 3. 借阅管理界面（Borrow.vue）

`<template>` 部分：借阅记录表格

`<script>` 部分：加载借阅记录、归还逻辑

```vue
<template>
  <div>
    <h2>借阅记录</h2>
      <!-- 借阅记录表格：数据源是records（借阅记录数组） -->
    <el-table :data="records" style="width: 100%">
      <el-table-column prop="id" label="ID"/>
      <el-table-column prop="username" label="用户"/>
      <el-table-column prop="bookTitle" label="图书"/>
      <el-table-column prop="borrowDate" label="借出时间"/>
      <el-table-column prop="returnDate" label="归还时间"/>
      <el-table-column label="操作">
        <template slot-scope="scope">
            <!-- 归还按钮：点击时传借阅记录的id -->
          <el-button size="mini" @click="returnBook(scope.row.id)">归还</el-button>
        </template>
      </el-table-column>
    </el-table>
  </div>
</template>

<script>
import axios from "axios";
export default {
  data() {
    return { records: [] };// 存所有借阅记录（表格数据源）
  },
    // 页面加载时自动拿借阅记录
  created() {
    this.getRecords();
  },
  methods: {
      // 拿借阅记录：发请求到后端的借阅列表接口
    async getRecords() {
      let res = await axios.get("http://localhost:8080/borrow/list");
      this.records = res.data.data;// 赋值给records，表格显示
    },
      // 图书归还：点击“归还”按钮时执行
    async returnBook(id) {
        // 发POST请求到后端的归还接口，传借阅记录的id
      await axios.post(`http://localhost:8080/borrow/return/${id}`);
      this.getRecords();// 重新拿借阅记录，表格刷新（归还的记录状态会变）
    }
  }
};
</script>
```

## 🔑 关键点说明

1. 前端 Vue 项目放在 `library-frontend/` 文件夹。
2. IDEA 里一般只跑 **后端 Spring Boot**；前端用 `npm run serve` 单独跑。
3. 前端调用后端接口 → 你写后端时就能用这些界面进行联调。
