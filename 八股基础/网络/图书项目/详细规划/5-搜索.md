# 二、短期方案 — 使用 MySQL FULLTEXT

## 1) Flyway migration：添加 FULLTEXT 索引

文件：`library-backend/src/main/resources/db/migration/V4__fulltext_index_books.sql`

```sql
-- 为 books 表创建 FULLTEXT 索引，便于 MATCH ... AGAINST 搜索
ALTER TABLE books
  ADD FULLTEXT idx_fulltext_title_summary (title, summary);

-- 如果需要对作者也做全文匹配，可以：
ALTER TABLE books
  ADD FULLTEXT idx_fulltext_title_author_summary (title, author, summary);
```

> 说明：MySQL FULLTEXT 对中文需要注意分词（MyISAM/InnoDB + ngram or plugin）。如果你主要是中文且需要更好分词，后期要迁移到 Elasticsearch。短期用 LIKE/partial match 或用 n-gram 插件是折中方案。

## 2) BookMapper 增强 — 新的 searchFulltext 方法

### BookMapper.java（新增方法签名）

路径：`library-backend/src/main/java/com/library/mapper/BookMapper.java`

```java
List<Book> searchFulltext(@Param("q") String q);
```

### BookMapper.xml（新增 SQL）

在 `library-backend/src/main/resources/mapper/BookMapper.xml` 中加入：

```xml
<!-- 全文搜索：使用 MATCH ... AGAINST -->
<select id="searchFulltext" resultMap="BookMap" parameterType="string">
  SELECT *, 
         MATCH(title, summary, author) AGAINST (#{q} IN NATURAL LANGUAGE MODE) AS relevance
  FROM books
  WHERE MATCH(title, summary, author) AGAINST (#{q} IN NATURAL LANGUAGE MODE)
  ORDER BY relevance DESC, updated_at DESC
</select>
```

> 说明：这里使用 NATURAL LANGUAGE MODE；也可以使用 BOOLEAN MODE 实现更多控制（支持 + - * 等运算符）。如果 q 很短（一个词），MySQL 有时把它当 stopword 忽略；在生产需调整 `ft_min_word_len` 等参数。

## 3) Service 层：支持按 mode 切换

新增 `SearchService` 接口和实现（短期实现只调用 MyBatis fulltext）。

```
library-backend/src/main/java/com/library/service/SearchService.java
package com.library.service;

import com.github.pagehelper.PageInfo;
import com.library.entity.Book;

public interface SearchService {
    PageInfo<Book> searchByMysql(String q, int page, int size);
}
```

实现 `SearchServiceImpl.java`：

```java
package com.library.service.impl;

import com.github.pagehelper.PageHelper;
import com.github.pagehelper.PageInfo;
import com.library.entity.Book;
import com.library.mapper.BookMapper;
import com.library.service.SearchService;
import org.springframework.stereotype.Service;

import javax.annotation.Resource;
import java.util.List;

@Service
public class SearchServiceImpl implements SearchService {

    @Resource
    private BookMapper bookMapper;

    @Override
    public PageInfo<Book> searchByMysql(String q, int page, int size) {
        PageHelper.startPage(page, size);
        List<Book> list = bookMapper.searchFulltext(q);
        return new PageInfo<>(list);
    }
}
```

## 4) SearchController（统一入口）

路径：`library-backend/src/main/java/com/library/controller/SearchController.java`

```java
package com.library.controller;

import com.library.common.Result;
import com.library.entity.Book;
import com.library.service.SearchService;
import com.github.pagehelper.PageInfo;
import org.springframework.web.bind.annotation.*;

import javax.annotation.Resource;

@RestController
@RequestMapping("/api/search")
public class SearchController {

    @Resource
    private SearchService searchService;

    // mode: mysql (default) | es (optional)
    @GetMapping
    public Result<PageInfo<Book>> search(@RequestParam String q,
                                         @RequestParam(defaultValue = "mysql") String mode,
                                         @RequestParam(defaultValue = "1") int page,
                                         @RequestParam(defaultValue = "10") int size) {
        if (q == null || q.trim().isEmpty()) {
            return Result.error("query is required");
        }
        if ("es".equalsIgnoreCase(mode)) {
            // 如果 ES 还没上线，提示
            return Result.error("ES mode not configured");
        } else {
            PageInfo<Book> info = searchService.searchByMysql(q, page, size);
            return Result.success(info);
        }
    }
}
```

# 三、长期方案 — Elasticsearch（可选，面试亮点）

如果你需要更好的中文分词、同义词、错别字纠正、自动补全、权重打分等能力，就迁移到 ES。下面给出 docker-compose、索引 mapping、Java 接入示例（Spring Data ES 或 RestHighLevelClient）。

## 1) docker-compose 添加 Elasticsearch（示例）

在项目根的 `docker-compose.yml`（dev）添加：

```yaml
elasticsearch:
  image: docker.elastic.co/elasticsearch/elasticsearch:7.17.9
  container_name: lib_elasticsearch
  environment:
    - discovery.type=single-node
    - bootstrap.memory_lock=true
    - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
  ulimits:
    memlock:
      soft: -1
      hard: -1
  ports:
    - "9200:9200"
  volumes:
    - esdata:/usr/share/elasticsearch/data

volumes:
  esdata:
```

> 说明：7.x 系列兼容 Spring Data ES 4.x；若采用 8.x 需要额外配置安全插件。开发建议用 7.17.x。

## 2) 创建 books 索引 mapping（示例，支持中文 ik analyzer）

如果你在 ES 上使用中文分词插件（IK），mapping 示例：

## 4) ES 同步策略（如何将 MySQL 数据推送到 ES）

- 启动时做完整 reindex（从 DB select all -> bulk insert into ES）。
- 增量：在 books CRUD create/update/delete 时同步（同步 API 里顺序：DB 写成功 -> send ES update; 若 ES 写失败，做重试/放入消息队列）。建议用 MQ（Rabbit/Kafka）异步可靠写入 ES，并用 dead-letter 监控失败。

# 五、测试与验证（必须做）

1. **功能测试**
   - q 为短词、长句、包含作者名、isbn 查询：返回合理结果。
   - 空查询/SQL 注入字段测试（例如传入 `' OR 1=1 --`），确保参数化使用 safe SQL（MyBatis 参数替换已做）。
2. **性能测试**
   - 并发搜索压力测试（k6/jMeter）模拟 100–1000 rps，观察 DB/ES CPU 与响应。MySQL FULLTEXT 在高并发下会成为瓶颈，ES 更擅长读扩展。
3. **边界测试**
   - 非法字符、超长 q、极短词（2 字以内）测试 MySQL 行为（注意可能返回空）。
4. **回归测试**
   - CRUD 后检查搜索结果是否立刻反映（若使用缓存/ES 同步，可能延迟），写自动化集成用例检验 eventual consistency 场景。
